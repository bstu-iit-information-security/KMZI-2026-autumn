# Лабораторная работа №5 — Квантовые сумматоры. Алгоритм Гровера

**Вариант: 4**  
**Язык:** Python  
**Библиотеки:** Qiskit, Qiskit Aer, NumPy, Matplotlib

## Содержание

- `lab5.py` — реализация заданий 1–7.
- `requirements.txt` — необходимые Python-библиотеки.
- `results/` — сюда автоматически сохраняются CSV-таблицы и графики после запуска.

## Требования

- Windows 10/11
- Python 3.10 или новее (рекомендуется Python 3.12)
- Интернет для установки библиотек

## Установка на Windows 11

Откройте папку проекта в Проводнике, нажмите на адресную строку, напишите `cmd` и нажмите Enter.

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его:

```powershell
.venv\Scripts\activate
```

Установите зависимости:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск

Запустить всю лабораторную:

```powershell
python lab5.py --task all
```

Запустить отдельное задание:

```powershell
python lab5.py --task 1
python lab5.py --task 2
python lab5.py --task 3
python lab5.py --task 4
python lab5.py --task 5
python lab5.py --task 6
python lab5.py --task 7
```

Все таблицы и графики будут записаны в `results/`.

## Что реализовано

1. Полный сумматор на пяти кубитах, реализация через два полусумматора, тестирование таблицы истинности и ripple-carry сумматоры на 2, 3 и 4 разряда.
2. Логическая функция варианта 4:
   `F(A,B,C,D) = NOT(A OR B) AND (C XOR D)`.
   Выполняется проверка всех 16 входных комбинаций и очистка вспомогательных кубитов.
3. Модель деполяризующего шума для однокубитных вентилей и CX.
4. Функции `build_oracle(n, marked)` и `build_diffuser(n)`, проверки операторов и вероятностей алгоритма Гровера.
5. Эксперимент с отмеченным состоянием из методички `|1010011>`, N=128, включая анализ числа shots.
6. Алгоритм Гровера для нескольких отмеченных состояний при N=64.
7. Индивидуальный вариант 4: N=32, отмеченное состояние `|00110>`.

## Важное замечание

Экспериментальные результаты зависят от seed симулятора и случайной выборки. При повторном запуске отдельные экспериментальные частоты могут немного измениться. Точные вероятности Statevector при этом должны оставаться неизменными.

Папка `results/` заполняется после запуска программы. Её содержимое можно коммитить на GitHub вместе с исходным кодом.
